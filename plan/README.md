## 状态门禁

- 状态统一为 planned、active、blocked、awaiting_review、done。active、blocked、awaiting_review合计最多1个当前计划；blocked与awaiting_review仍占用当前计划，不得绕开启动下一项。
- 当前计划完成全部验收、记录验证结果并提交后，才可将其标记done并启动下一计划。
- 001—003仅使用虚构数据构建纯前端，不执行采集、剪辑、发布，不写真实Excel。用户确认Demo前禁止004真实业务接入。
- 003实现与测试检查完成后停在awaiting_review；用户明确确认界面后才可标记done，完成验证和提交后允许004启动。
- 每个计划遵循[_template.md](_template.md)，需求变化先记入计划或[backlog.md](backlog.md)。

## 固定边界

本地网页不上线，先单机，局域网多主机留到008。在线商品库、协同表和飞书账号数据仅通过人工下载的副本只读使用，禁止写回在线文档。总控状态独立保存，源任务表不改，阶段工作副本隔离。

任务Excel固定A:P共16列，不能新增列或改变含义。J的数字或空白仅是发文端口记忆提示，不是链接、网络端口或任务ID；实际执行端口单独配置。完整商品ID按文本保真，包含19位ID。

品类验证必须同时具备完整商品分类副本与账号F允许类别证据；缺失或错配阻止后续操作。素材按账号隔离，候选素材由人工在原界面确认；剪辑在原GUI人工确认产量、正式词表、装饰并启动，总控读取报告；发文由人工启动。

发文每批最多5账号，使用5个独立xlsx，各自Sheet1仅1账号且无中间空行；超过5账号分批。千川读取`Root/抖音名称/完整商品ID/成片/*.mp4`，抖音读取`Root/抖音名称/完整商品ID/成片/变速/*.mp4`。普通成片与变速成片分别判定ready。脚本仅在隔离工作副本回写M“已发布”、N“计划已发布”，必须区分软件报告与人工核验。
