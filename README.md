# 总控制台

运营任务、素材、剪辑和发文交接的本地总控制台。先确认流程和纯前端 Demo，再按计划接入单机 MVP，最后支持局域网分工。

## 项目入口

- [项目规范](项目规范.md)：范围、只读数据边界和开发顺序。
- [计划索引](plan/README.md)：当前唯一计划、依赖和验收状态。
- [任务表与交接契约](docs/任务表与交接契约.md)：原16列及三个软件的交接规则。

在线文档始终只读。真实业务表、账号信息、视频和机器配置只存本地，不进入仓库。

## 本地 Demo

双击 `启动Demo.bat`，或在本目录执行：

```powershell
python tools/preview_server.py
```

打开 <http://127.0.0.1:8860/>。页面只有虚构数据与模拟操作，服务仅绑定本机。停止时按 Ctrl+C。端口占用时可用 `python tools/preview_server.py --port 8861`，不会结束已有进程。

网页包含任务进度、原表16列、数据快照、五槽发文交接、主机规划和两张可交互设计图。右上角切换场景可检查品类门禁、成片缺失、失败重试和六账号分批。

## 日常使用

```powershell
# 查看修改
git status

# 提交修改（将文件名替换为实际修改的文件）
git add <文件名>
git commit -m "说明本次修改"

# 同步到 GitHub
git push
```

主分支为 `main`。新功能可使用独立分支开发：

```powershell
git switch -c feature/功能名称
```

请勿提交密码、访问令牌或真实的 `.env` 配置。需要示例配置时，使用不含敏感信息的 `.env.example`。
