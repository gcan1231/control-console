运营任务、素材、剪辑和发文交接的本地总控制台。先确认流程和纯前端 Demo，再按计划接入单机 MVP，最后支持局域网分工。

## 本地任务工作台

双击 `启动总控制台.bat`，或运行：

```powershell
python tools/local_server.py
```

打开 <http://127.0.0.1:8861/>。服务只绑定本机，运行状态、只读来源快照和隔离准备副本保存到被Git忽略的`runtime/`。使用Python 3.10及以上，不需要安装第三方包。停止按Ctrl+C；端口占用可指定`--port 8862`，不会结束已有进程。`--runtime-dir`可指定另一个独立数据目录。

1. 点击“导入本地副本”，选择原格式任务表xlsx，预览精确16列和逐行问题后确认导入。
2. 导入人工取得的账号副本，按A:F读取身份和F允许品类，确认工作表、表头行及完整性。
3. 导入完整商品分类副本，逐Sheet选择ID列和类别列，或使用有分类名称的Sheet作为来源；商品标题不构成分类证据。
4. 在“数据快照”维护显式类别别名。缺失、冲突、不匹配、问题行及重复候选会显示阻塞原因。
5. 任务详情可保存独立备注和重复行核对；重启后任务UUID、来源证据和记录保留。M/N只表示来源有回执，未人工核验。

任务表原文件不会被修改。当前只准备互相隔离的阶段字节副本，尚未调用找素材、剪辑或发文软件。再次导入同文件和解析选项不会创建重复任务；改动文件后会保留新的来源批次，疑似同日重复任务需核对。

## 虚构界面 Demo

双击 `启动Demo.bat`，或在本目录执行：

```powershell
python tools/preview_server.py
```

打开 <http://127.0.0.1:8860/?workspace=demo>。页面只有虚构数据与模拟操作，服务仅绑定本机。停止时按 Ctrl+C。端口占用时可用 `python tools/preview_server.py --port 8862`，不会结束已有进程。本地任务服务页面也可通过“工作空间”选择“虚构演示”，演示数据不写入本机数据库。

网页包含任务进度、原表16列、数据快照、五槽发文交接、主机规划和两张可交互设计图。右上角切换场景可检查品类门禁、成片缺失、失败重试和六账号分批。

## 日常使用

```powershell
# 查看修改
git status

# 提交修改（将文件名替换为实际修改的文件）
git add <文件名>
git commit -m "说明本次修改"

# 同步到 GitHub
git push
```

主分支为 `main`。新功能可使用独立分支开发：

```powershell
git switch -c feature/功能名称
```

请勿提交密码、访问令牌或真实的 `.env` 配置。需要示例配置时，使用不含敏感信息的 `.env.example`。
