# 自动发文接口与使用

2026-10-16，007范围修订。入口仍为`/publish.html`；旧人工交接保留，与新自动执行按包互斥。008未启动，所有接口仅在本机环回服务开放。

## 启动与日常操作

本机项目虚拟环境已安装Playwright 1.64.0。`启动总控制台.bat`优先使用本项目`.venv`。在其他电脑部署时应重新创建环境，不复制本机`.venv`：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-publishing.txt
```

不用运行`playwright install`，模块连接你已经打开的Chrome端口，不另建账号profile，也不关闭账号浏览器。正常页面导航和上传只会在你明确启动批次后发生；只读身份探测不发布内容。

1. 在原流程完成素材、普通/变速成片核验，再准备五槽交接包。实际端口显式填写，J保留原记忆提示。
2. 在“自动发文”选择业务账号与已打开端口，点击只读探测。抖音号/UID必须可靠匹配；千川还须匹配广告账户。缺失、冲突、登录失效或多标签身份不明确时阻止绑定/执行。
3. 保存本账号确认模板。抖音选择推荐封面或指定图片；千川明确预算、ROI、出价方式、投放目标和位置。金额没有预填默认。运行时冻结模板版本；指定封面复制并校验，不能靠修改原路径影响已准备运行。
4. 选择包与批次，核对本批账号、成片和千川参数并勾选启动确认。每批最多5个账号，各账号独立进程、内部顺序执行；超过5个账号手工启动下一批。抖音每条变速视频独立发布，千川按商品普通成片创建计划后准确关闭新计划。
5. 查看逐项状态、精确平台ID和错误。暂停/停止作用于后续动作；已提交千川计划仍优先完成关停。不明结果只允许重新查询，不提供重新发布捷径。
6. 全包所有批次所需视频均确认发布、千川计划均确认关闭后，在交接包区域回收自动执行回执，再沿用独立人工核验。此步骤不改XLSX；M/N兼容回执和证据快照仅独立存储。

## 状态与证据

独立执行表记录run、账号、逐视频/计划item、模板版本、文件身份、提交意图、平台ID与结果证据。`before_submit`在最终点击前持久化。提交后失败、崩溃或无法关联本次回执进入unknown；千川已取得计划ID但关停未确认进入closing_failed，突出计划ID并停止该账号。

`pending_review`只表示平台审核中，不算已发布。平台报告结果与人工verified独立。回收检查每个冻结视频均有唯一对应证据，不能重复使用列表首条作品ID，也不能省略同商品的其他视频。返回了别的ID的查询结果不能覆盖原项。

执行进程退出由其父服务监测；服务重启只恢复状态，不自动重新派生提交。Windows进程探测使用只读进程查询API，不使用具有终止进程语义的`os.kill(pid,0)`。进程ID无法确认时保守保留未知，不尝试杀死浏览器。

## 本机接口

所有POST沿用Host、Origin、X-Console-Token检查，准备与状态查询不会隐式执行。原`/api/publishing/run`仍不存在。

| 方法 | 路径 | 请求 |
|---|---|---|
| GET | `/api/publishing/execution/state` | bindings、templates、runs、逐项aggregate、capabilities |
| POST | `/api/publishing/execution/probe` | port；读取本机CDP及现有平台页面，证据5分钟有效 |
| POST | `/api/publishing/execution/bind` | accountId、port、uid、advertiserId、confirmed:true |
| POST | `/api/publishing/execution/template` | accountId、platform、parameters、confirmed:true |
| POST | `/api/publishing/execution/start` | packageId、batchIndex（从1开始）、confirmed:true |
| POST | `/api/publishing/execution/control` | runId、可选accountId、action=pause/resume/stop |
| POST | `/api/publishing/execution/reconcile` | runId、itemId；仅查询既有精确平台ID，不提交/关停 |
| POST | `/api/publishing/collect_native` | packageId、confirmed:true；完整成功证据回收 |

抖音parameters为`{coverMode:"recommended"}`，或`{coverMode:"file",coverPath:"本机绝对路径"}`。文件封面限普通PNG/JPG/JPEG/WebP且20MiB以内。千川为`{dailyBudget:"明确正数",roi:"明确正数",bidStrategy:"界面实际选项",target:"界面实际选项",placement:"界面实际选项"}`；不猜平台支持值，无对应字段或选项时停止。

start幂等：同包同批返回已有run，不新增尝试。账号/端口互斥，模板及绑定执行期间不能更改。已人工handoff/回收的包不能转自动；已有executionOwner的包不能交回旧软件。更换模式、端口或清空回执不会生成自动重发机会。

## 日志与兼容性限制

自动执行开始时向现有日志中心登记每账号独立UTF-8追加日志，含可信taskId、runId和itemId。日志写入和读取不直接修改业务成功状态。日志配置失败时本批不派生执行进程；worker启动诊断单独保留本地。

平台适配器使用真实页面动作与正常UI请求响应关联，不直接调用猜测的私有发布API。身份读取、导航、推荐封面、商品挂载、上传完成、回执、精确ID行和关停均有明确后置检查。页面改版、信息缺失或回执无法关联时会停止；不是所有Chrome/CDP版本和平台页面都已证明兼容。

当前已完成本地工程与隔离测试，尚未在公司账号验证当前DOM、实际千川参数选项和真实平台发布结果。不能把mock页面或CDP连接成功当作真实业务成功。首次公司机器验收应先单账号，再五账号，最后多批；保留旧软件，禁止用同一个已执行/未知的包试新旧两种方式。
