采用[Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)中与项目适用的原生标签、焦点可见、可访问名称、控件忙态、长内容换行、缺图反馈和容器滚动规则。用户指定的14px密集表格、本地字体和浅色优先；不引入网络字体或额外框架。

## 实际限制

真实账号资料必须由操作者核对F允许范围、UID和合作码。缺年份统计日期须明确设置副本年份；未核对表头的非标准Sheet不能用于新选品。来源修订后旧草稿不静默换内容，需重新核对选品。下载和任务生成只证明数据流程通过，不证明真实业务软件执行成功。日志006B、发文007和局域网008未在本计划实现。
