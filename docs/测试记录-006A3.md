# 006A3 每日选品接入验证

日期：2026-10-15。范围仅当前006A3，沿用用户选定A布局与本机三项UI技能规则。重复整理、测试及独立审查委托用户指定GPT-6.1-sol low子代理。

## 检查方式

业务自动化测试使用虚构账号、商品和临时运行目录。浏览器请求限制在临时回环服务，下载文件只在临时目录解析；不注册插件、不运行按键脚本、不启动采集/剪辑/发文，不向在线文档写入。真实副本兼容性只读统计，不在报告和Git中保存业务行。

覆盖草稿版本与持久恢复、账号F/UID资料缺失、来源表头/年份/同日冲突、C/O映射、19位商品ID、J个人提示、L:P空白、预设保留草稿、事务回滚、预览失效、同token重启幂等、追加保留旧任务/锁/冻结、下载固定16列，以及Host/Origin/token和异常参数边界。

浏览器检查1440、1920、800、390宽，中文组合输入、对话框焦点恢复、正常生成、缺资料阻断、来源变化和XLSX下载。截图保存在被忽略的test-results，仅虚构数据。父代理目视1440与1920截图，四列表格及左右账号/草稿与定版布局一致。

- Node非浏览器31项通过；新正式选品浏览器完成草稿编辑/恢复、预设保留、中文组合输入/焦点、16列确认/下载、F与UID阻断、来源变化阻断，四尺寸无整页横向溢出，无页面异常或外部请求。父代理目视1440/1920截图。
- 原local和account-capture浏览器回归通过。workbench首次因旧测试把来源form内所有input当路径而严格定位失败；新增年份后改为data-wbs-path精确定位，补年份控件可见断言，重跑8组与四尺寸通过。该失败不是产品功能失败。
- 真实商品副本只读解析仍1060条，1003条有可靠表头证据，1024条有完整统计日期，无条目需要补年份。主分类完整性为true。食品-宠物421条、百货个护家清427条有可靠表头；母婴57条未核对，不放行；另155条为精选商家/本地上传标签来源，不能独立作为主分类选品行。

## 界面审查

采用[Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)中与项目适用的原生标签、焦点可见、可访问名称、控件忙态、长内容换行、缺图反馈和容器滚动规则。用户指定的14px密集表格、本地字体和浅色优先；不引入网络字体或额外框架。

## 实际限制

真实账号资料必须由操作者核对F允许范围、UID和合作码。缺年份统计日期须明确设置副本年份；未核对表头的非标准Sheet不能用于新选品。来源修订后旧草稿不静默换内容，需重新核对选品。下载和任务生成只证明数据流程通过，不证明真实业务软件执行成功。日志006B、发文007和局域网008未在本计划实现。
