# 总控制台 Windows 便携版

适用Windows 10/11 64位。先把整个ZIP解压到有写入权限的目录，再双击“启动总控制台.cmd”或“Start.cmd”。不需要安装Python、Node.js、pip或npm，不会在首次启动下载运行依赖。保持服务窗口打开；Ctrl+C可停止总控。账号浏览器由用户管理，停止总控不会关闭Chrome。

启动成功后自动打开本机网页，默认地址为 http://127.0.0.1:8861/ 。若8861已被占用，程序提示失败，不会结束其他程序。可在命令行运行 `Start.cmd --port 8862`。`Start.cmd --no-browser` 可关闭自动打开网页。

## 数据和迁移

程序旁的data文件夹保存本机任务、导入副本、交接记录、日志及执行状态。首次启动才创建，发布包不含任何真实账号或业务数据。不要删除data来重试结果不明的发布。迁移时先停止本机总控和执行任务，保留完整data及原视频目录；原电脑的绝对路径、软件位置和账号端口须在新电脑重新核对。更新程序前备份data，勿用空白包覆盖已有数据。

## 业务前置条件

总控自带运行时、页面、截图图像组件和Playwright驱动；找素材与剪辑软件仍按各自便携包运行，不包含在本包。真实发文仍需要公司现有Chrome、已登录账号、用户已经打开的对应CDP端口和访问平台的网络。总控不创建或搬运账号登录环境，不会自动发布；须在页面核对账号、模板并明确启动批次。

截图文字识别使用Windows自带OCR。缺少简体中文OCR组件时会提示不可用，仍可用复制表格文本导入，不影响总控启动；此包不自动安装或修改Windows组件。在线文档永久只读，使用人工取得的本地副本。

## 离线检查与故障

运行 `Start.cmd --check` 可校验包内文件和驱动，检查不启动Chrome、不连接账号、不发布视频。组件缺失时请重新完整解压，不需要安装开发环境。若目录不可写，移动到本人可写目录；公司安全软件或策略拦截时向公司管理员提供提示，不要关闭安全防护。

当前真实平台页面、发布和千川精确关停仍待公司机器验收。隔离测试通过不等于真实业务成功。包内第三方许可证随运行时与依赖保留。
