# 004 本地导入接口

服务仅127.0.0.1，默认8861。现有8860纯Demo继续可用（URL加`?workspace=demo`）；本机服务默认本地任务，`?workspace=demo`保留虚构演示。JSON接口无CORS。写请求带`X-Console-Token`（GET health取得），Origin若存在必须同源；Host仅接受绑定地址及localhost。

## 请求

- `GET /api/health` → `{ok:true, version:1, token, capabilities:["local-import","state-storage"]}`。
- `GET /api/state` → `{ok:true,tasks,batches,sources,aliases,counts}`。
- `POST /api/inspect`，`{filename,content}`，content为文件字节base64。→ `{ok:true,sha256,sheets:[{name,headers:[{column,label}],rowCount}],limits}`。只解析，不存业务数据。
- `POST /api/import/preview`及`POST /api/import/commit`，`{kind,filename,content,options}`。kind为tasks/products/accounts/collaboration；预览不落库；提交原子保存。
- `POST /api/settings/aliases`，`{aliases:{来源类别:对应类别}}`；保存显式映射并重新校验，不能通过备注绕过分类门禁。
- `POST /api/tasks/review`，`{taskId,note,duplicateConfirmed}`；仅更新独立备注/重复行核对与审计，不改业务字段或源文件。

文件限20MiB，xlsx解压数据限128MiB，有效行上限50000；错误响应`{ok:false,error:{code,message,details}}`。不读取客户端任意路径、不接受其他Excel格式。导入请求的选项与文件来源保留在来源记录。

## 解析选项

任务固定Sheet1第1行A:P，不需映射选项。

账号：`{sheet,headerRow:1,complete:false}`。A运营人/B抖音账号/C抖音名称/D UID/E合作码/F允许类别；表头行可为0表示首行即数据。

商品：`{complete:false,sheets:[{sheet,headerRow:1,idColumn:"G",categoryColumn:"",categoryFromSheet:true}]}`；选择类别列时categoryFromSheet为false，类别列用Excel列字母。分类Sheet按其实际名称作为证据，经显式alias匹配账号类别；Sheet1等通用名不能作为类别证据。选项必须覆盖所需分类，完整性由操作人明确声明；缺少任一任务商品分类仍阻塞该任务。

协同副本：`{sheet,headerRow:1}`，只保留来源参考，不写回、不把其中日志导入为运行状态。

## 返回数据

导入预览/提交：`{ok:true,kind,sourceId,reused,rowCount,validCount,issues:[{row,code,message}],previewRows:[{row,fields}],batchId?}`。结构错误HTTP422，单行错误保留于结果及任务门禁；同文件同解析选项返回同sourceId/batchId与任务UUID，不清空已有备注/审计。

state.tasks每项：`{id,batchId,sourceRow,sourceSheet,fields:[16个显示字符串],cellMeta:[{type,value,hyperlink}],accountId,category,allowedCategories,stage,validation:{ok,code,reason,issues},duplicateConfirmed,note,events:[{time,text}],sourceReports:{m,n}}`。stage为material或reported；reported只表示来源有M/N回执，未做平台/人工核验。validation阻塞独立于stage；004没有阶段推进、成片数量或发文动作API。

cellMeta额外保存原XML raw、xlsxType和style索引；安全整数保留数值类型，长数值按词法值检查，原完整字节保存在快照。日期显示按工作簿1900/1904 epoch解析，原序列及类型独立保留。

state.batches：`[{id,sourceId,filename,createdAt,taskCount,workCopies:{material,editing,publishing}}]`；三个路径仅为隔离准备副本，不表示已调用软件。

state.sources：`[{id,kind,filename,sha256,createdAt,complete,active,rowCount,options}]`；最新提交的每种参考快照为active。每个任务的分类校验引用当前active商品和账号证据；类别未知、冲突、账号名称不一致或数值长ID不安全均阻塞。

counts：`{tasks,eligible,blocked,reported,batches}`。事件记录真实本地导入/核对事实，不使用Demo的模拟完成状态。业务数据不进入Git。

重复候选按日期原显示值、账号和完整商品ID提示，跨来源批次同样核对；不同日期或不同账号仍独立。精确同文件/解析选项重试不创建任务；不同来源的相同行不会被静默合并。

读取依据：[Microsoft SpreadsheetML单元格数据类型](https://learn.microsoft.com/en-us/office/open-xml/spreadsheet/how-to-retrieve-the-values-of-cells-in-a-spreadsheet)、[Excel日期系统](https://support.microsoft.com/en-us/excel/date-systems-in-excel)。来源字节快照保持不变，数值ID从原XML词法值检查；不执行公式或使用缓存结果冒充来源值。
