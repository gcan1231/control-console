## 选型与模块

Python Playwright用于CDP连接和可诊断页面动作；与现有Python后端一致，避免增加第二套生产语言。参考social-auto-upload的抖音挂商品与上传流程，千川独立实现。其tencent模块是视频号，不能当作千川。Puppeteer作为方案对照；DrissionPage当前自定义许可不作为本公司项目底座。

## 结果与回退

上传成功、已提交、审核中、已发布、计划已关闭和独立人工核验分别记录。没有可靠身份、作品/计划ID、模板字段或页面能力时阻止自动执行。重启不自动恢复提交；只读重新查询不得产生发布动作。千川提交后优先准确关停，即使操作人此时暂停或停止，也不能丢弃已创建计划的处理记录。

真实平台页面兼容性、公司Chrome版本和真实业务结果仍需公司机器实机验收；本地仿真通过不等于平台成功。旧软件、原始表格、浏览器profile保留，新包已经提交或结果不明时不得转交旧软件重发。
