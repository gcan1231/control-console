# 每日选品与任务编制

用户已选A账号工作台：左侧账号及目标，中间商品列表，右侧今日草稿。正式入口为`/selection.html`，原三版对照演示保留在`/selection-comparison.html`。正式页只访问本机数据提供层。

## 使用顺序

1. 在“来源与账号资料”登记人工下载的商品库、协同表绝对路径。缺年份的月日必须由操作者核对副本所属年份后填写“商品统计年份”；留空则不推断。
2. 在截图粘贴区按Ctrl+V，或点击“从剪贴板粘贴截图”；也可选择PNG/JPEG，或在右侧粘贴账号A:H表格文字。截图添加后进入本机识别预览，切换账号逐个核对并明确保存。按钮读取受浏览器限制时改用粘贴区Ctrl+V或选图。F为允许选品范围、H为公司账号编号；任务执行名称、UID和合作码分别核对。H不代表执行端口。
3. 打开每日选品，选任务日期和账号。默认账号所属运营人，可明确改派；商品默认最近统计日期，也可查看历史。
4. 加入草稿，修改短标题、运营人、可选J个人提示和K店铺。草稿保存在本机运行库；切换账号、日期或数量预设不清空草稿。
5. 预览固定16列，解决来源或资料问题，再勾选确认生成。生成只追加该账号当日新任务，原任务身份、商家锁及冻结记录保留。数量目标只提醒，不强制限制。
6. 下载当日或当前账号的固定Sheet1 XLSX；任务继续在原工作台做素材、剪辑交接。公司协同表由人工登记，系统不在线写回。

## 字段与来源

任务A为选定日期；B为所属运营人或明确改派；C/D为核对后的执行账号名称和抖音号；E默认商品标题，可改短标题；F保留完整商品ID文本；G来自商品库O列，C列商家字段另存；H取商品实际链接；I按账号、抖音号、UID、合作码四行编排。J仅可选个人提示，K默认空，L:P生成时为空。

来源记录保留工作表、行、分类、标签、图片索引、统计日期及佣金/销量原文。非标准表头、来源冲突、缺F范围不能选用；UID或合作码未补齐可存草稿，但不能生成。历史选品和公司协同为提醒，商家发送标记与执行成功分别记录。

## 本机接口

所有接口仅本机回环服务。POST沿用Host、同源和X-Console-Token校验，JSON大小上限不变。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/selection/state` | 账号、目标、预设、草稿、任务与来源提示 |
| GET | `/api/selection/products` | 按账号、任务日、统计日、搜索、异常开关分页浏览，每页50条 |
| GET | `/api/selection/product?productId=…` | 核对商品来源记录 |
| GET | `/api/selection/export?date=…&accountId=…` | 内存生成XLSX下载，账号可省略，不改源表 |
| POST | `/api/selection/add` | 以账号、日期和来源记录ID建立草稿 |
| POST | `/api/selection/update`、`/remove` | 带草稿id和version修改或移除 |
| POST | `/api/selection/target`、`/preset`、`/apply-preset` | 数量目标0—1000、版本化预设及应用 |
| POST | `/api/selection/preview` | 固定16列预览及来源/资料问题 |
| POST | `/api/selection/generate` | `token`与`confirmed:true`原子追加；同token持久幂等 |

来源记录ID不等同商品ID。生成前再次验证草稿版本、来源版本和已有任务；来源变化必须重新核对。请求中断时先刷新任务状态，不盲目重复生成。源文件、在线文档和三个业务软件均不由本功能修改或启动。
