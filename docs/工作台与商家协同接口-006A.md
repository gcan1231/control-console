# 006A 工作台与商家协同

## 日常流程与来源
本地Excel选品 → 导入预览与修订 → 人工登记公司协同 → 按账号交接素材与剪辑。首页默认最新导入任务日期，保留原表16列；商品库只供参考，不新增网页选品。

- `POST /api/reference/register`：`{kind:"products"|"collaboration",path:本机绝对xlsx路径}`。同源token保护，拒网络共享、URL和链接路径。单XML32MiB、相关XML总64MiB；只读XML与drawing索引，不整体上传GB媒体。图片惰性读取，单图8MiB。
- 商品三主分类：食品-宠物、百货个护家清、母婴；精选商家、本地上传产品仅来源标签。母婴表头第3行，没有主类不得猜测。
- 协同自动识别固定16列表头，前置说明/案例排除；P后非空业务值、无效日期、公式、不可靠长ID保留问题，不参与可靠匹配；格式化空远列忽略。
- H紫为商品链接已发商家，I紫为账号资料已发商家。识别可见字体/富文本紫色`9A38D7`与`800080`，空样式不算；无紫仅为未发现标记。任意一项即锁A:I，首次锁定版本与来源证据永久保留，后续消色不自动解锁，本期无解除入口。
- `POST /api/reference/refresh`：`{}`。正式服务每10秒检测已登记本地文件size/mtime；失败保留旧快照与错误，不访问在线文档。
- 来源身份包括相关XML逻辑SHA256、解析选项/版本和文件修订签名；该SHA不是整个原文件的SHA。图片按来源版本缓存，旧版未缓存图片拒用新版代替。

## 工作台与账号
`GET /api/state`增加`referencePaths`、`accountProfiles`及任务的`archived`、`frozenEvidence`、`product`、`collaboration`。协同信息含两项发送标记、锁定、当日匹配/差异、历史和来源证据，与软件阶段独立。

当日按规范日期/账号/完整商品ID匹配并比较A:I，J提示差异不算登记冲突；多候选不合并。历史仅提醒任务日期以前的同账号同商品，跨账号保持独立；提醒不阻止有意识重做。

`POST /api/accounts/verify`：`{profiles:[{accountId,name,allowed:[类目],evidence:独立F列核对说明}],confirmed:true}`。只保存显式核对的账号，不从选品或紫色生成允许类目。别名仍用原接口，已交接任务冻结原别名。

## 重导与交接
- `POST /api/tasks/import/preview`：`{filename,content,options}`，返回原预览及`changes/conflicts/revisionToken`。同步已有商家锁证据，不修改任务业务字段。
- `POST /api/tasks/import/commit`：同预览内容加`revisionToken`。任务、来源、锁、别名变化使旧预览失效；按本次日期+运营人范围核对，不归档其他运营任务。
- 唯一匹配保持内部ID；未锁且未交接可更新，移除仅归档，可恢复。重复对应或保护冲突整次拒绝，不部分更新；旧/新值及来源独立存版本。最新行序与起始批次身份分开保存，首行插入不打乱界面或工作表交接顺序。
- 商家锁保护A:I；交接冻结整条任务和商品/账号来源、别名。原16列不加内部字段，原文件不改。
- 素材冻结确认IDs、逐条成功报告和真实文件证据齐全且校验通过后自动就绪。后台只对已送预览、未完成包只读回收，不搜索/下载/重试。
- `POST /api/editing/verify-batch`：`{taskIds:[同账号1—100任务],kind:"normal"|"speed",confirmed:true,note:""}`。全部报告/文件检查后单事务保存，必须明确已观看；备注可空，两种成片独立且幂等，原单条verify兼容空备注。
