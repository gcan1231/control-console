## 统一入口

```powershell
# 列出完整清单，不启动测试
python -B tools/run_single_machine_checks.py --list

# 完整单机自动化（同样可用npm run test:single-machine）
python -B tools/run_single_machine_checks.py

# 定向运行
python -B tools/run_single_machine_checks.py --suite backend
python -B tools/run_single_machine_checks.py --suite unit
python -B tools/run_single_machine_checks.py --suite browser
```

可用--python/--node指定实际解释器。需要本机已有Chrome和Playwright；若Playwright在外部目录，设置PLAYWRIGHT_MODULE。入口也会检查项目node_modules及所选Python旁的bundled Node依赖目录，不安装依赖或修改系统设置。

入口自动发现全部测试清单，强制纯Demo使用自己启动的随机端口只读预览，不使用正式8861；逐项保存日志、耗时、退出码和JSON汇总。任一失败总体退出非0，不自动重试掩盖失败；超时仅终止自己启动的测试进程树。可用--timeout设置单脚本时限（默认600秒）。报告保存在test-results/single-machine/时间戳目录。

本轮全套按等价分组执行，由指定GPT-6.1-sol low代理记录。统一入口另外通过Node组实际运行、独立只读预览启动/关闭、故意缺少Node工具返回失败码1的烟测；这项故意失败不计为产品测试失败，也没有宣称统一入口自身又完整重复执行了一遍全部测试。
