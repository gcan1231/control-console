# 007 独立成果接入与软件定位

2026-10-16。最终选版是旧统一布局（0cd713c）和A石墨极简。五种结构不用于正式页；旧预览已恢复，正式任务、选品、发文、日志及接入页统一石墨配色。当前仍是007，008暂缓。

## 如何使用

从侧栏“已有成果接入”进入 `/external.html`。已有任务可直接选；尚未导入时，选本地任务表，预览固定Sheet1第1行A:P及修订差异，再明确确认导入。商品和账号品类证据仍须在来源页核对。表格及在线来源均不写回。

1. 没做过素材：在素材交接准备独立工作表；不知道路径时进入接入页“自动识别软件”，找不到再选软件数据目录。
2. 已有素材：选择账号、任务日期和商品行，类型选素材，选成果根目录并预览。逐个观看文件、核对归属和日期后填写说明并确认接纳，再到剪辑交接准备独立工作副本；仍由人在原剪辑GUI启动。
3. 已有成片：类型选普通/变速成片，独立预览和人工接纳，再到发文页准备交接。普通、变速分别有资格；千川需要普通，抖音需要变速，双模式须两类齐全。准备不启动发文，后续仍须核对账号、端口、模板并明确启动。
4. 可先接纳素材，再接纳同任务在外部完成的成片；已接纳成片后不能倒退准备素材或剪辑。已有进行中的剪辑/发文交接不能覆盖，先处理原交接记录。

目录规则中的“根目录”是账号目录的上一级，不是视频所在的最深层目录：

```text
所选根目录/
  抖音名称（与任务表C列一致）/
    完整商品ID（与F列一致）/
      原素材.mp4
      成片/
        普通成片.mp4
        变速/
          变速成片.mp4
```

仅按直接目录取MP4，不猜名称、不递归汇总其他账号。一个目录本次只能分配一行任务。同账号商品在其他日期也有任务时，预览明确提示其他日期；本次仅接纳到用户选择并确认的任务ID，不把历史行合并。J原值保留，仅是记忆提示。

## 来源和人工核验

预览检查当前品类资格、无发布回执、目录归属、完整清单、大小、SHA256、修改时间和基本MP4容器头；不以容器头或文件存在判断实际视频内容合格。确认前必须人工观看全部文件。

接纳时复验任务、证据和源文件全集，复制后再核对原件，写入runtime/external独立副本、清单、人工说明和审计记录。原件不移动、不改名、不回写。重复确认同一预览复用原接纳；来源变化必须重新预览；失败回滚本次隔离副本。

外部接纳记录与material/editing软件回执独立。界面所示“已人工接纳”是历史核验记录，准备下一阶段时会复验副本身份；修改或删除副本会阻止继续。不会生成伪造的素材/剪辑成功报告。

本轮不自动采用外部软件报告。未知JSON/报告显示“未验证”；发现已识别的原生报告时阻止该接入，要求走原报告回收流程处理可能冲突。已有阶段交接不被覆盖。符号链接、junction、重解析路径及UNC不接入；不自动修复或迁移业务软件。

## 软件定位与选择器

自动定位仅检查已核对的LOCALAPPDATA/DouyinSelector数据根；选择目录后最多扫描120个目录、3层，跳过源码/测试/依赖目录。不搜索整盘，不读取源码测试配置，不启动原软件。

候选依据runtime.json、material.db只读SQLite结构及标记端口的loopback `/api/health`协议。版本、build、交接能力或数据库结构不匹配的候选不能保存。多候选由用户明确选择；保存时重新核对标记、数据库身份和健康状态，失败保留原配置。端口来源与任务J列无关。

目录选择使用Windows内置PowerShell WinForms对话框，固定系统PowerShell路径，无Python Tk、Node或额外安装要求。取消不清空当前路径；系统不允许打开窗口时提示手填路径。实际公司系统策略及窗口交互仍需实机验证。

## 本地接口和存储

新增接口沿用Host、同源Origin、X-Console-Token和JSON边界：

| 接口 | 输入 / 结果 |
|---|---|
| POST /api/software/discover | 可选directory；返回候选id、版本、端口、数据库、eligible及依据 |
| POST /api/software/select | candidateId；复核后保存素材连接，不启动程序 |
| POST /api/local/pick | kind=directory或taskWorkbook；返回path/cancelled |
| POST /api/external/preview | taskIds、kind=materials/finished、root；返回未核验预览及逐任务文件清单 |
| POST /api/external/accept | previewId、confirmed=true、非空note；返回独立人工接纳记录 |
| GET /api/external/state | externalPreviews、externalAcceptances、externalTasks |

SQLite新增external_previews与external_acceptances，原业务16列无迁移。任务状态接口增加独立task.external；剪辑和发文的资格读取外部证据，但不冒充原软件阶段状态。所有真实文件、数据库、机器配置和日志仅本地保存，不提交Git。
