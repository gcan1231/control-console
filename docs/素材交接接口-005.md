# 005 素材交接与结果回收

## 范围

总控生成一个账号独占的 `Sheet1.xlsx` 和输出根目录，向已运行的素材软件发送预览请求。操作人继续在原界面建任务、搜索、预览、勾选并「确认并输出」。总控不启动原软件、不调用搜索或下载入口，不写公司在线文档，也不初始化或迁移原软件数据库。

所有业务文件只保存在本机 `runtime/material/<交接ID>/`。原始来源快照与原任务表保持不变，业务资料不进入Git。

## 工作表与身份

每包1—100个任务，全部属于同一个账号，并通过最新商品类别、账号F类别、重复行校验；来源M/N有发布回执的任务禁止素材交接。一个包内不允许同商品重复，否则软件商品目录会合并。任务已经属于另一个包时禁止重新打包，使用已有交接继续或登记重试。

交接ID由任务ID集合确定，重复准备复用原包，不覆盖被改动的工作表。A:P表头和16个业务字段的文本值保留，19位商品ID与J原值不截断；日期使用导入时已核对的显示文本。生成单一Sheet1，连续行，不复制来源公式或超链接，不向原表加列。工作表全部使用文本单元格，J仍是端口记忆提示。原始字节与单元格元数据仍在004来源中。

`manifest.json`独立保存交接行→内部任务ID→来源批次/行→完整商品ID→分类证据及输出目录。输出路径为独占包根下 `media/抖音名称/完整商品ID`。不静默清洗或截断非法账号目录名，发现Windows不安全名称时阻止准备。

## 结果与人工关卡

1. 用户点击发送预览，仅POST固定integration路径；操作人随后在原软件完成实际操作。
2. 点击回收，GET固定row/materials路径读任务映射与候选；使用独立SQLite连接 `mode=ro`、`query_only=ON`读取download_jobs，不导入原Repo，不调用状态修复接口。软件已退出、行映射消失、候选响应不完整或超过100条时明确阻塞，不猜测归属。
3. 聚合该软件task_id所有冻结选择和逐条结果，较新单条结果覆盖较早结果。最新重试只成功了一部分素材，不能掩盖其他历史失败。所有冻结ID必须仍在完整候选中，当前aweme_id与报告一致且原软件eligibility.allowed明确为true；缺失或新阻止不能沿用旧成功。未解决失败、运行中、缺报告、缺精确output_result都阻塞。同工作表行在原GUI改过输出根、留下其他目录的历史作业时严格阻塞，不静默丢弃无法证明范围的失败记录。
4. 核对每条输出的aweme_id、精确目录、文件名、字节数、非空MP4容器头和SHA256；只读任务目录内直接文件，不混用缓存、其他账号或子目录。文件头与摘要检查不代表视频已解码或内容可用。
5. 报告与文件一致标为「软件报告完成，待人工复核」。操作人必须明确勾选在原软件确认输出并复核内容，填写记录后，才标「素材已人工复核」并允许006剪辑交接。不会自动剪辑。

每次回收保存不可变JSON报告快照。人工记录绑定报告摘要、文件摘要和当前分类证据。回收发现结果改变、文件丢失或失败会撤销ready；重新回收完全相同的报告与文件保留已完成复核。确认时再次读取文件摘要，防止回收后文件被替换。

状态：prepared待执行、review待原软件确认、reported软件报告完成待复核、failed阻塞、retry已登记人工重试、ready人工复核完成。登记重试不删除旧报告或文件、不重建任务、不调用原软件reset/retry；重复登记相同记录幂等，操作人回原软件处理失败行。

## HTTP接口

沿用004本机Host、同源、X-Console-Token及JSON限制。GET `/api/state`增加 `materialSettings`、`materialPackages`、`materialTasks` 与 `tasks[].material`。

| POST路径 | 请求 |
|---|---|
| `/api/material/settings` | `{port: 整数, database: 已存在本机SQLite绝对路径}` |
| `/api/material/prepare` | `{taskIds: 一个账号的任务ID数组}` |
| `/api/material/send` | `{packageId}`；仅发送预览路径 |
| `/api/material/collect` | `{packageId}`；回收只读结果，单行错误记录为failed |
| `/api/material/confirm` | `{taskId, note, confirmed: true}`；仅reported/ready，最新校验与文件仍通过 |
| `/api/material/retry` | `{taskId, note}`；仅失败任务登记重试 |

当前真实业务验收仍需操作人使用实际工作副本在原界面执行。自动测试仅使用虚构OOXML、临时作业库、临时MP4字节与本机替身HTTP服务，不能宣称实际素材内容质量或真实下载成功。
