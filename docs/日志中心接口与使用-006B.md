# 日志中心

入口为`/logs.html`，任务工作台侧栏“日志中心”可进入。沿用已选Shadcn Admin浅色、系统字体、14px内容和独立数据提供层。上方集中查看来源，下方按软件、级别、关键词筛选，50条分页；任务详情可查看可靠关联摘要并跳到当前任务日志。

## 使用与边界

本机服务每3秒采集已启用来源；页面每3秒读取副本，可暂停页面刷新或立即刷新。暂停页面刷新不会停止后台采集。离开未保存的来源表单会提醒，刷新不重绘填写内容。读取状态不代表业务软件正在运行，也不代表任务成功。

展开设置，填写软件、名称、本机日志文件绝对路径、编码和可选同目录轮转模式，勾选启用并保存。查看来源可修改，取消启用可停采。只接受.log/.txt及数字轮转（如app.log.1），不接受网络、设备、数据库、程序或视频路径。不会递归搜索目录。未启用的来源不读文件，缺失文件或编码错误在该来源显示，不启动软件补产日志。

已启用的精确日志文件暂不存在时显示“等待日志文件”（waiting_file），不按读取失败处理、不生成原目录或文件；文件自然生成后下一轮自动采集。主文件等待重建时，现存轮转文件继续读取。权限或编码问题仍显示读取失败。最近读取时间只在确实读到文件后更新，等待状态不伪造成功时间。

独立数据库位于运行目录的log-center.sqlite3；不把运行日志放进任务表16列，也不更新任务状态、商家锁、独立报告或人工核验。真实路径、配置和日志副本不提交Git。清理仅删除超过30天的总控事件副本，不删除原软件日志或业务报告。

## 读取和任务归属

支持UTF-8、带BOM的UTF-16；自动模式依据BOM，否则UTF-8。完整换行后才导入，中文跨读取块或尚未完成的行留待下一轮。每文件每轮最多256KiB/2000行、总计1MiB、同目录轮转最多32文件，达到预算显示分批读取；超过预算的超长单行暂不导入，不能宣称已完整采集。

游标持久化并处理重命名轮转、文件替换、长度缩短和边界内容重建；已读完的小文件另用有界整体指纹，修改mtime不会重复导入，同长中部改写可识别。大文件仅比较256字节头及128字节已读尾指纹，不保证识别指纹范围外的中部原位改写。

有可解析ISO年月日时间的行按日志时间保留30天；无可靠时间按文件mtime判定保留，显示为“读取时间”，不伪造原日志时间。发文区域化时间可能落入mtime后备规则。未标级别为UNKNOWN；级别只是展示信息。日志保留原行，不将异常堆栈续行猜成独立业务结果。

仅显式`taskId=内部ID`或`taskId:内部ID`且属于本机已知任务的标记才关联；其他行保留为软件级事件。不会按J提示、商品ID、线程、标题或账号猜任务。现有软件若不输出可信内部ID，任务摘要为空，仍可在日志中心查看全部软件日志。

## 本机接口

| 方法 | 路径 | 含义 |
|---|---|---|
| GET | `/api/logs/state` | 软件来源状态、事件和总数；software/level/search/taskId/page筛选，50条分页 |
| GET | `/api/logs/summary?taskId=…` | 可信任务日志计数和最近一条，不改变任务 |
| POST | `/api/logs/configure` | 保存独立日志来源，默认禁用；id可选，software/label/path/encoding/rotationGlob/enabled |
| POST | `/api/logs/poll` | 立即读取已启用来源并返回副本状态 |

接口沿用本机Host、同源Origin和POST token边界。查询不开放任意文件路径读取。软件取material/editing/publish；级别取DEBUG/INFO/WARN/ERROR/CRITICAL/FATAL/UNKNOWN，筛选大小写不敏感。
